# Instant ink - Apollo ID Migration

What is apollo ID migration?

Apollo Migration replaces manual retailer name matching with Apollo Partner IDs (PPIDs) as the single source of truth across HP systems. This shift standardizes partner identities, eliminates fuzzy matching, reduces manual operations, and improves data quality and hierarchy visibility across all Retailer Compensation, Amplify, Enrollment, and Sales attribution workflows.

Apollo provides enterprisewide, consistent partner master data (PPID, partner names, hierarchies). This aligns CSS, PA, CO and other teams on the same identifiers, enabling automation, accuracy, and reduction of operational cost and errors.

Core Changes

- All partner attribution moves from retailer names to Apollo PPIDs.
- Apollo becomes the master dimension table for partner data across CSS.
- Retailer merges, name changes, and hierarchy updates are owned by the Apollo team and cascade to all systems.
- Apollo partner names often differ from current retailer names; teams must adopt Apollo naming.

Current Status

- All source systems now provide PPIDs.
- Apollo Partner table is live and refreshed daily.
- IISB & CR tables are ready in UAT, and channel compensation pipelines and UI reports are being tested for impact as a result of these changes and any logic changes are being implemented simultaneously. Field name changes shared with all teams.
