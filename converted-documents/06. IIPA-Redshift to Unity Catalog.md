# IIPA-Redshift to Unity Catalog Migration

IIPA Retailer Compensation Redshift to Unity Catalog Migration

Migration Steps, Source Table Mapping, and IIPA Writing Tables

Overview
The migration of IIPA Retailer Compensation data from Redshift to Unity Catalog involves several key steps to ensure efficient data management and controlled access. This process includes creating dedicated teams and access groups in Unity Catalog, migrating tables, and updating data reading processes for improved security and accessibility.

Major Migration Steps

- Establish the IIPA Unity Catalog team within the workspace.
- Create different access groups for granular, role-based access control for both internal and external teams.
- Begin reading all source IIDE tables through Unity instead of Redshift.
- Migrate existing Retailer Compensation (RC) tables to Unity.
